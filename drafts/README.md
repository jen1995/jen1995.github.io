# Drafts

Shared scratch space for work-in-progress: raw notes, half-baked posts, ideas, TODO lists.

Nothing here gets published — Hugo only builds what is inside `content/`. When a draft matures into a post, move it to `content/posts/<post-name>/index.md` (see the main README for the post format).

Feel free to organize this folder however is convenient: subfolders per topic, per author — anything goes.
